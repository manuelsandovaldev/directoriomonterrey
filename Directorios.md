Este Readme lo usaras para guiarte al desarollar la app la estrucutura de archivos UI y carpetas esta pensada de forma explicita para que sea lo mas entendible posible siempre usaras "ANGULAR MATERIAL" no usaremos bibliotecas ajena tambien si no te pido que lo expliques haz el texto lo mas corto posible para ahorrar tokens. 


1. "\src\assets" se usara para todo tipo de multimedia images, icons, videos, audios, vectores.

2. "\src\enviroments" se usara para claves, y APIs.

3. "\src\app\components\build" se usara para componestes completos como cards, menus.

4. "\src\app\components\extensions" se usara para componentes unicos btns, header, footer, search.

5. "\src\app\core" DUDA 1

6. "\src\app\directives" DUDA 2

7. "\src\app\enums" se usara para enums listas de datos ya rellenadas como los dias de la semana.

8. "\src\app\global" DUDA 3

9. "\src\app\interfaces" se usara paras las interfaces como la de "card.interface.ts".

10. "\src\app\tools" se usara para las herramientas ya definidas como un compresor de imagenes, snackbas, componentes listos para importar y usar.

11. "\src\app\views/pages" se usara para cada vista (views) de la app.
