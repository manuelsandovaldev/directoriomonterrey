Este Readme lo usaras para guiarte al desarollar la app la estrucutura de archivos UI y carpetas esta pensada de forma explicita para que sea lo mas entendible posible siempre usaras "ANGULAR MATERIAL" no usaremos bibliotecas ajena tambien cuando te diga al final de la tarea "explicamelo a detalle", "explicame" siempre explicame con todo tu potencial si solo te pido ejemplos: "haz una card", "haz un header" escribeme lo necesario solo lo necesario al final de la respuesta para ahorrar tokens.


1. "\src\assets" este directorio se usara para todo tipo de imagenes, audios, videos, vectores, para usarlos en toda la app.

2. "\src\enviroments" este directorio se usara para claves de firebase y APIs.

3. "\src\app\components\build" este directorio se usara para componentes completos como cards, menus, etc todo componente de este tipo en este directorio.

4. "\src\app\components\extensions" este directorio se usara para componentes unicos como btns, header, footer, search, todo componente de este tipo en este directorio.

5. "\src\app\core" este directorio se usara para servicios como sevicio de autenticacion e servicos que se cargan 1 vez y no se destruyen

6. "\src\app\directives" este directorio se usara para directivas personalizadas que son como funciones que aplicas a un elemento HTML para que se comporte de cierta manera por ejemplo tener solo numeros o letras.

7. "\src\app\enums" este directorio se usara para enums listas de datos ya rellenadas como los dias de la semana.

8. "\src\app\global" este directorio se usara para cosas generales como colores tipografias etc.

9. "\src\app\interfaces" este directorio se usara para todas las interfaces de toda la app como la de "card.interface.ts".

10. "\src\app\tools" este directorio se usara para herramientas ya definidas como un compresor de imagenes, snackbas, componentes listos para importar y usar.

11. "\src\app\views/pages" este directorio se usara para cada vista (views) y pagina de la app.
